# Подсказки: Ansible: настройка и идемпотентность

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Persistent host directory важна: если хранить всё только внутри disposable controller, первый шаг будет «новым» при каждом запуске.
2. Режимы файлов запиши строками '0644'/'0755', чтобы избежать неоднозначной интерпретации YAML.
3. Для template сначала добавь mount исходника. Ошибка file not found не связана с Jinja2-подстановкой.
4. Handler в этом стенде моделирует реакцию. Не пиши в резюме управление systemd, если работал только с marker.
5. Для валидации переменной используй assert до template. Не маскируй неправильное значение автоматической заменой на 1.
