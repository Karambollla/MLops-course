# Ansible: template и handler

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

Редактируй `playbook.yaml` и `housing.env.j2`. Добавь проверку положительного целого WORKERS, template и notify/handler. `report.json` заполни данными трёх своих запусков: workers1, workers2, повтор workers2. В `handlers` перечисли имена реально выполненных handlers. Готовые тесты проверяют изменения файла и отсутствие повторного handler; содержание playbook и причину идемпотентности объясни вручную. `solution.py` — необязательный read-only сборщик.

Используй task-local compose.yaml, добавь в него требуемые mounts, если добавляешь файлы.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Добавь template с переменной WORKERS, ограниченной положительным целым. Измени WORKERS с 1 на 2, покажи один ожидаемый change и срабатывание handler только при изменении. Для контейнера без systemd используй marker с понятным назначением. После повторного запуска снова changed=0.

Смонтируй свой template в controller через дополнительный volume Compose: текущий стенд монтирует только inventory/playbook. Проверь `--check --diff` перед применением и сравни с реальностью.

## Проверка

```bash
make task TASK=12-ansible/02-template-handler
```

Для Python CLI:

```bash
python scripts/run_task.py run 12-ansible/02-template-handler -- --help
```

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.

## Критерии и завершение

Тесты проверяют согласованность заполненного отчёта. Покажи три исходных вывода Ansible и diff файла; объясни границы handler в контейнере без systemd. Останови task-local compose-проект после занятия.
