## Один notebook

Открой [housing.ipynb](housing.ipynb) и выбери ядро существующей `.venv` с Python 3.12. Условия, заготовки, зависимости, примеры и все проверки находятся внутри. Первая ячейка устанавливает закреплённые зависимости именно в выбранное ядро.

| Раздел notebook | Что реализовать | Как проверить |
|---|---|---|
| Baseline | MAE/RMSE, split и постоянный прогноз | Выполнить проверочные ячейки после функций |
| Кандидат | Pipeline, выбор по validation, повторяемое обучение | Ячейки проверки прогнозов и четырёх артефактов |
| Анализ ошибок | Квартили и географическая граница | Ячейки с группами, ошибочными входами и границами |

`make task`, `make tasks` и `make tasks-collect` этот модуль не выполняют. Проверочная ячейка работает с текущими определениями в ядре: после изменения функции повторно выполни её ячейку, затем проверку. До реализации ожидается `NotImplementedError`.

## Данные

Из корня курса явно загрузи датасет, если его ещё нет:

```bash
python -m housing.data --output work/housing.csv
```

Notebook читает существующий CSV; маленькие проверки используют синтетические таблицы без сети. При перезапуске ядра выполняй определения последовательно. Не используй метрики test для выбора конфигурации.

## Результат

Последняя ячейка содержит готовую функцию сохранения. Она записывает `model.joblib`, `metrics.json`, `manifest.json`, `split.json` непосредственно в `work/artifacts/`. Отличающиеся файлы заменяются только при явном `replace=True`; отдельного экспортёра нет.

Сохрани notebook перед переходом дальше: `housing.train` и `housing.evaluate` читают только отмеченные ячейки с импортами и функциями из файла. Установка пакетов, проверки, графики и финальное сохранение при этом не выполняются. Для повторного обучения в пайплайне остаётся CLI:

```bash
python -m housing.train --data work/housing.csv --output work/runs/example --seed 42
```

В `train` должны использоваться аргументы, а не интерактивные переменные. Сохрани CSV и артефакты для следующих модулей. Перед коммитом очисти выводы ячеек; `.ipynb_checkpoints/` исключены из Git.
