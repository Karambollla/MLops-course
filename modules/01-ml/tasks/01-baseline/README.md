## Зачем начинать с постоянного ответа

До выбора алгоритма нужен проверенный способ разделить данные и посчитать ошибку. Иначе красивая MAE кандидата может возникнуть из другого test или неверного расчёта. Baseline — простое сравнение, здесь постоянный ответ, обученный на среднем target train. Разбор вычислений дан в [примере baseline](../../README.md#разобранный-baseline-и-выбор-кандидата), назначение выборок — в [разделе о split и утечке](../../README.md#разбиение-и-утечка).

## Исходное состояние и маленькая проверка

После [табличной темы Python](../../../00-python/tasks/03-tabular-analysis/README.md) готов `work/housing.csv`, понятны восемь признаков и target `MedHouseVal`. В этом задании реализуются три отдельные функции: метрика проверяет массивы, split возвращает исходные позиции строк, baseline использует оба результата. Обучение кандидата и сохранение полного bundle появятся в следующей теме; здесь не нужно изобретать другой train CLI.

Возьми train-ответы `[1,3]`, validation `[100]`, test `[20,40]`. Baseline должен предсказывать 2; validation MAE=98, test MAE=28. Если он предсказывает другое среднее, проверь, какие строки переданы в `fit`. Независимо проверь метрику на `[0,2]` против `[0,0]`: MAE=1, RMSE=√2. Два разных результата позволяют поймать случайное использование MAE вместо RMSE. Проверка split должна сравнивать полные списки индексов с двухэтапным разбиением, а не только размеры.

## Где работать и контракт

Редактируй `modules/01-ml/tasks/01-baseline/solution.py`. Дополнительные тесты размещай в этой же папке.

`regression_metrics(y_true, y_pred) -> dict[str,float]`: одинаковые непустые одномерные конечные массивы, иначе ValueError; ключи mae/rmse в единицах target. `make_split(n_rows: int, seed: int = 42) -> dict[str,list[int]]`: train/validation/test 60/20/20, сначала test_size=.2, затем validation_size=.25 от остатка через sklearn train_test_split с тем же seed; исходные позиционные индексы. `fit_baseline(frame, split: dict) -> dict`: проверь ровно FEATURES + TARGET, fit DummyRegressor(mean) только на train, верни validation/test mae/rmse. Сохрани split и вычисленные baseline-метрики с единицами 100000 USD.

## Среда и зависимости

Базовая среда, numpy/pandas/scikit-learn, установленный housing; CPU.

Предшественник: 00-python. Загрузи housing.csv один раз; тесты используют локальные малые таблицы.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=01-ml/01-baseline
```

Тесты функций работают offline на маленьких входах и временных файлах. До реализации ожидается `NotImplementedError`; ошибка импорта означает проблему подготовки среды. Проверка функций не заменяет описанный опыт на данных или стенде.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("01-ml/01-baseline")` из Python. CLI не требуется.

## Требования практического опыта

Проверь восемь признаков из `housing.features.FEATURES`, target и отсутствие неожиданных столбцов. Создай split 60/20/20 с seed 42, сохрани индексы в JSON. На train обучи DummyRegressor. Реализуй `regression_metrics` и проверь:

```bash
RUN_EXERCISES=1 python -m pytest labs/housing/tests/test_exercises.py -v
```

Тест pipeline останется красным до задания 2. Для отдельной проверки метрик добавь `-k evaluation`. Артефакт: baseline MAE/RMSE на validation и test с единицами измерения.

## Пример корректного результата

`regression_metrics([1,3], [2,2])` возвращает `{"mae": 1.0, "rmse": 1.0}`. На 10 строках split 60/20/20 содержит 6/2/2 уникальных индекса без пересечений; повтор с тем же seed даёт те же индексы.
