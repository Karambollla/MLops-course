## Где работать и контракт

Редактируй `modules/01-ml/tasks/03-error-analysis/solution.py` (физическая заготовка рядом). Дополнительные свои тесты и `report.md` размещай в этой же папке. Полных решений в заготовке нет.

`quartile_errors(y_true, y_pred) -> list[dict]` проверяет одинаковые непустые одномерные конечные массивы, группирует по pd.qcut(y_true, 4, labels=False, duplicates="drop"), возвращает по непустым квартилям упорядоченные {quartile: 1..4, count, mae, rmse}. Если все targets одинаковы, одна группа quartile=1. `geographic_split(frame, latitude_cutoff: float) -> dict` делит исходные индексы на train (Latitude < cutoff) и test (>=); пустая сторона вызывает ValueError. В report.md: таблица квартилей и размеров, опыт scaler.fit до split с объяснением утечки (этот артефакт не использовать), random против geographical split, ограничения данных и единицы target.

## Среда и зависимости

Базовая среда, pandas/numpy/sklearn; CPU.

Зависит от 01-ml/01-baseline и 02-candidate. Автотесты проверяют расчёт групп, а объяснение утечки оценивается вручную.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=01-ml/03-error-analysis
```

До реализации ожидается RED: `NotImplementedError`, а не ошибка импорта зависимостей. После реализации все offline-тесты должны быть зелёными. Они создают временные данные через pytest tmp_path; полный housing автоматически не скачивается.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("01-ml/03-error-analysis")` из Python. CLI не требуется.

## Требования практического опыта

Составь таблицу ошибок по четырём квартилям target. Проведи намеренно ошибочный опыт: обучи scaler до split и объясни утечку. Не используй этот артефакт дальше. Дополнительно сравни random split с географическим и опиши, какой вопрос отвечает каждый.

## Приёмка и очистка

Пройди все тесты `test_task.py`, сохрани перечисленные артефакты и добавь объяснение решений/ограничений в `report.md`. Для инфраструктурных опытов приложи реальные команды и вывод: offline проверки не доказывают развёртывание, доступность удалённого сервера или качество объяснения. Ручная оценка: воспроизводимость шагов, соответствие исходному контракту, объяснение причины сбоя и корректное восстановление.

Docker не требуется. Временные тестовые файлы убирает pytest. Сохрани CSV, split, отчёты и модель в `work/` для следующих модулей; окружение можно завершить `deactivate`. Учебные DVC demo/remote удаляй только после экспорта результатов.
