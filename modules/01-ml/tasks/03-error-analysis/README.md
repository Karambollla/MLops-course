# Анализ ошибок

## Зачем смотреть за пределы общей MAE

Кандидат из [предыдущей темы](../02-candidate/README.md) может проходить общий порог, но сильно ошибаться на дорогих районах. А случайное перемешивание способно дать более лёгкую оценку, чем перенос в новый регион. Здесь одна метрика раскладывается по группам и меняется сам вопрос оценки. Смысл этих опытов разобран в [анализе групп](../../README.md#анализ-групп-и-неверные-успехи).

## Откуда берутся входы

Нужны собственный обученный Pipeline и test-индексы из `split.json`; `y_true` берётся из target этих строк CSV, `y_pred` — из `pipeline.predict` на тех же строках только с FEATURES. Заготовка предоставляет функции анализа квартилей и географического разбиения. Первая использует расчёт MAE/RMSE baseline, вторая возвращает исходные метки индекса, сохраняя связь с таблицей.

На targets `[0,1,2,3,4,5,6,7]` и прогнозах 0 общая MAE=3.5. Четыре пары дают 0.5/2.5/4.5/6.5; рядом с каждой ошибкой должно быть `count=2`. Для широт `[33,35,36]` с индексами `[10,20,30]` и границы 35 train содержит `[10]`, test — `[20,30]`: равенство относится к test. Не путай эти метки с позициями `[0,1,2]`. Намеренный scaler-fit до split выполняется отдельно от корректной модели: нарушение границы существует, даже если метрика изменилась мало.

## Где работать и контракт

Редактируй `modules/01-ml/tasks/03-error-analysis/solution.py`. Дополнительные тесты размещай в этой же папке.

`quartile_errors(y_true, y_pred) -> list[dict]` проверяет одинаковые непустые одномерные конечные массивы, группирует по pd.qcut(y_true, 4, labels=False, duplicates="drop"), возвращает по непустым квартилям упорядоченные {quartile: 1..4, count, mae, rmse}. Если все targets одинаковы, одна группа quartile=1. `geographic_split(frame, latitude_cutoff: float) -> dict` делит исходные индексы на train (Latitude < cutoff) и test (>=); пустая сторона вызывает ValueError. Верни вычисленные ошибки по квартилям. Сравни метрики random и geographical split на собственных данных; артефакт ошибочного scaler.fit до split не используй дальше.

## Среда и зависимости

Базовая среда, pandas/numpy/sklearn; CPU.

Зависит от 01-ml/01-baseline и 02-candidate. Автотесты проверяют расчёт групп и границу географического разбиения. Утечку предотвращает fit preprocessing только на train.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("01-ml/03-error-analysis")` из Python. CLI не требуется.

## Требования практического опыта

Составь таблицу ошибок по четырём квартилям target. Проведи намеренно ошибочный опыт: обучи scaler до split и сравни полученные метрики с корректным Pipeline. Не используй этот артефакт дальше. Дополнительно сравни random split с географическим на одинаковых метриках; смысл разбиений разобран в теории модуля.
