# Подсказки: ML и оценка моделей

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Два вызова `train_test_split`: первый с `test_size=0.2`, второй с `test_size=0.25` на оставшейся части. Разбивай вместе признаки, target и идентификаторы.
2. Для RMSE в выбранной версии sklearn есть `root_mean_squared_error`; тест проверяет само значение, поэтому допустим и явный квадратный корень MSE.
3. Pipeline должен принимать DataFrame с каноническим порядком столбцов. Сохрани estimator вместе с preprocessing.
4. Для первого запуска ансамбля ограничь число деревьев и `n_jobs`; ноутбуку не нужны сотни параллельных задач.
5. Порог 0,9 относится к отношению MAE на одинаковом test, а не к R². Не превращай порог в подбор по test.
