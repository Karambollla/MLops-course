# Подсказки: ML-сервис, Docker и CI

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. FastAPI TestClient запускай через `with`: так выполняется lifespan, который загружает модель.
2. Для HTTP/pipeline-паритета сделай один DataFrame в каноническом порядке; сравни массивы через allclose.
3. В Docker путь модели `/models/model.joblib`, на ноутбуке — `work/artifacts/model.joblib`. Volume соединяет эти два пространства имён.
4. При Permission denied проверь права чтения файла для UID 10001. Не переводить весь контейнер на root ради одного артефакта.
5. Не считай пропущенные учебные тесты доказательством реализации. Запусти `make task TASK=03-service-ci/01-api-contract` и добавь свои интеграционные проверки; ML проверяй ячейками notebook.
