# Подсказки: Terraform: инфраструктура как код

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Ошибка соединения provider часто связана с endpoint, а не с HCL. Сначала проверь docker info.
2. Не используй JSON.stringify как shell quoting для переменных: endpoint можно задать обычным `export TF_VAR_docker_host='unix:///путь'`.
3. Plan после ручного удаления должен предлагать create, а не доказывать, что state исчез.
4. Required provider фиксирует источник и версию. Init без сети требует заранее подготовленного plugin cache.
5. Не применяй старый saved plan после изменения конфигурации: создай новый и просмотри его.
