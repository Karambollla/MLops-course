# Подсказки: ClearML: задачи, артефакты и агенты

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Offline mode надо включить до Task.init. Не указывай выдуманный API endpoint ради прохождения задания.
2. В `finally` закрой task, чтобы локальная сессия сохранилась и при исключении.
3. Если задача висит в queue, проверь agent, имя очереди и доступ к исходникам. Очередь не является worker.
4. Удалённый agent не видит `work/housing.csv` на ноутбуке автоматически. Явно передай версию и источник данных.
5. На ARM сначала inspect образов; не расходуй часы на тяжёлую эмуляцию в день интенсива.
