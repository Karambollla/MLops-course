# Подсказки: Воспроизводимость, данные и DVC

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Путь `../dvc-remote` вычисляется относительно DVC-проекта; проверь `dvc remote list` до удаления рабочего CSV.
2. Если `dvc pull` сообщает, что данные уже есть, это не ошибка. Проверь наличие рабочего файла и `dvc checkout`.
3. Индексы split должны ссылаться на исходные строки, а не на новый RangeIndex после случайной сортировки.
4. Для версий Python-пакетов используй `importlib.metadata.version`; для хеша файла — чтение бинарными блоками через hashlib.
5. Не включай абсолютный путь ноутбука в обязательный интерфейс bundle: его нельзя воспроизвести на другой машине.
