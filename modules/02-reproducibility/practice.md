# Практика: Воспроизводимость, данные и DVC

[Теория](README.md) · [Подсказки](hints.md)

## Подготовка

Создай отдельное окружение и установи `dvc==3.59.2`. Выполняй команды внутри `work/dvc-demo`, а не в случайном существующем репозитории:

```bash
mkdir -p work/dvc-demo work/dvc-remote
cp work/housing.csv work/dvc-demo/housing.csv
cd work/dvc-demo
git init
dvc init
dvc remote add -d local ../dvc-remote
dvc add housing.csv
dvc push
```

Добавь в Git `.dvc`, `.dvcignore`, `.gitignore` и `housing.csv.dvc`. Commit выполняется после настройки собственного имени и email Git.

## Задание 1. Восстановить данные

Запиши SHA-256 CSV. Удали только рабочий CSV, сохранив `.dvc`-указатель, и восстанови `dvc pull`. Сравни хеши. Затем добавь собственную вторую версию CSV и покажи переключение данных через предыдущий Git commit и `dvc checkout`. Исходный датасет курса при этом не меняется.

## Задание 2. Манифест и контракт

Доработай train CLI: `manifest.json` содержит seed, хеш CSV, split, версии, параметры и список признаков. Bundle `model.joblib` — словарь с ключами `schema_version=1`, `pipeline`, `features`, `model_version`; точные требования есть в [контракте](../../labs/housing/README.md). Сделай два запуска с одинаковыми входами и сравни прогнозы на фиксированных 20 строках через `numpy.allclose` с `rtol=1e-6`, `atol=1e-8`.

## Задание 3. Восстановить эксперимент

Сохрани окружение и команды так, чтобы новая временная директория получала те же данные, split и метрики в пределах допуска. Добавь отрицательную проверку: изменённый SHA-256 или другой порядок признаков не должен незаметно обслуживаться как прежняя модель.

## Критерии готовности

- [ ] CSV восстанавливается из DVC remote с тем же хешем.
- [ ] В Git нет данных, весов, окружения и секретов.
- [ ] Для модели можно назвать исходные данные, код, конфигурацию и среду.
- [ ] Численная эквивалентность отделена от совпадения байтов.

## Завершение

Вернись в корень курса. Учебный remote оставь до завершения проекта. Удаление `work/dvc-demo` и `work/dvc-remote` после экспорта отчёта затрагивает только эту лабораторную.
