## Где работать и контракт

Редактируй `modules/02-reproducibility/tasks/01-data-version/solution.py` (физическая заготовка рядом). Дополнительные свои тесты и `report.md` размещай в этой же папке. Полных решений в заготовке нет.

`sha256_file(path: Path, chunk_size: int = 65536) -> str` считает SHA-256 потоково, неположительный chunk_size вызывает ValueError. `verify_restore(original_hash: str, restored: Path) -> None` поднимает ValueError при несовпадении, не меняет файл. Создай собственный work/dvc-demo и local remote work/dvc-remote, dvc==3.59.2 в отдельной среде. dvc init/add/push; добавь в учебный Git только .dvc, .dvcignore, .gitignore и pointer, после настройки имени/email сделай commit. Удали только рабочий CSV, восстанови dvc pull и сравни хеш. Добавь вторую версию, переключи Git commit и выполни dvc checkout. Не меняй исходный housing.csv курса. Сохрани команды, оба commit/hash и результаты в report.md.

## Среда и зависимости

Базовая среда из SETUP: Python, pytest; CPU, Linux/macOS.

Зависит от 01-ml/02-candidate (исходные данные). DVC/Git действия выполняются вручную только внутри work/dvc-demo; тесты доказывают целостность файлов, но не факт восстановления из remote. Ручная приёмка: воспроизвести pull/checkout и проверить отсутствие CSV/весов/секретов в Git.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=02-reproducibility/01-data-version
```

До реализации ожидается RED: `NotImplementedError`, а не ошибка импорта зависимостей. После реализации все offline-тесты должны быть зелёными. Они создают временные данные через pytest tmp_path; полный housing автоматически не скачивается.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("02-reproducibility/01-data-version")` из Python. CLI не требуется.

## Требования практического опыта

Запиши SHA-256 CSV. Удали только рабочий CSV, сохранив `.dvc`-указатель, и восстанови `dvc pull`. Сравни хеши. Затем добавь собственную вторую версию CSV и покажи переключение данных через предыдущий Git commit и `dvc checkout`. Исходный датасет курса при этом не меняется.

## Приёмка и очистка

Пройди все тесты `test_task.py`, сохрани перечисленные артефакты и добавь объяснение решений/ограничений в `report.md`. Для инфраструктурных опытов приложи реальные команды и вывод: offline проверки не доказывают развёртывание, доступность удалённого сервера или качество объяснения. Ручная оценка: воспроизводимость шагов, соответствие исходному контракту, объяснение причины сбоя и корректное восстановление.

Docker не требуется. Временные тестовые файлы убирает pytest. Сохрани CSV, split, отчёты и модель в `work/` для следующих модулей; окружение можно завершить `deactivate`. Учебные DVC demo/remote удаляй только после экспорта результатов.
