# Восстановить данные

## Зачем восстанавливать байты, а не имя файла

Обученная модель зависит от содержимого CSV. Если файл изменился по прежнему пути, повтор той же команды уже проверяет другой эксперимент. Здесь контрольная сумма делает изменение наблюдаемым, а DVC связывает Git-версию небольшого указателя с данными в отдельном хранилище. Сначала прочти [цепочку Git/DVC](../../README.md#как-git-и-dvc-восстанавливают-одну-версию) и [смысл SHA-256](../../README.md#что-именно-доказывает-контрольная-сумма).

## Исходное состояние и разделение работы

Нужен CSV `work/housing.csv`, использованный [кандидатом](../../../01-ml/tasks/02-candidate/README.md). Работай с его копией в `work/dvc-demo`, исходный файл курса сохраняется. В `solution.py` реализуются две операции над файлами: потоковый хеш и отказ при несовпадении восстановления. DVC/Git-команды выполняются отдельно в учебном репозитории по [подготовке практики](../../practice.md#подготовка); автотест не заменяет удаление копии и её получение из remote.

Например, `x,y\n1,2\n` и `x,y\n1,3\n` имеют одинаковый размер, но разные SHA-256. После восстановления V1 ожидается хеш V1; после выбора commit V2 и `dvc checkout` — хеш V2. Если поменялся только commit, а рабочие байты остались V1, второй опыт не завершён. Сохрани соответствующие указатели и данные в remote до окончания проверки обеих версий; служебный checksum DVC не нужно вручную заменять своим SHA-256.

## Где работать и контракт

Редактируй `modules/02-reproducibility/tasks/01-data-version/solution.py`. Дополнительные тесты размещай в этой же папке.

`sha256_file(path: Path, chunk_size: int = 65536) -> str` считает SHA-256 потоково, неположительный chunk_size вызывает ValueError. `verify_restore(original_hash: str, restored: Path) -> None` поднимает ValueError при несовпадении, не меняет файл. Создай собственный work/dvc-demo и local remote work/dvc-remote, dvc==3.59.2 в отдельной среде. dvc init/add/push; добавь в учебный Git только .dvc, .dvcignore, .gitignore и pointer, после настройки имени/email сделай commit. Удали только рабочий CSV, восстанови dvc pull и сравни хеш. Добавь вторую версию, переключи Git commit и выполни dvc checkout. Не меняй исходный housing.csv курса. Проверь восстановление обеих версий по commit и SHA-256.

## Среда и зависимости

Базовая среда из SETUP: Python, pytest; CPU, Linux/macOS.

Зависит от 01-ml/02-candidate (исходные данные). DVC/Git действия выполняются вручную только внутри work/dvc-demo; тесты доказывают целостность файлов, но не факт восстановления из remote. Ожидаемое поведение на стенде: воспроизвести pull/checkout и проверить отсутствие CSV/весов/секретов в Git.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=02-reproducibility/01-data-version
```

Тесты функций работают offline на маленьких входах и временных файлах. До реализации ожидается `NotImplementedError`; ошибка импорта означает проблему подготовки среды. Проверка функций не заменяет описанный опыт на данных или стенде.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("02-reproducibility/01-data-version")` из Python. CLI не требуется.

## Требования практического опыта

Запиши SHA-256 CSV. Удали только рабочий CSV, сохранив `.dvc`-указатель, и восстанови `dvc pull`. Сравни хеши. Затем добавь собственную вторую версию CSV и покажи переключение данных через предыдущий Git commit и `dvc checkout`. Исходный датасет курса при этом не меняется.

## Приёмка и очистка

Запусти указанную выше команду `make task` после реализации и исправления ошибок. Проверяемые случаи перечислены в соседнем `test_task.py`.

Docker не требуется. Сохрани CSV, указатели DVC, manifest, split и модель до проверки восстановления. Учебные demo/remote удаляй только после сохранения нужных версий в другом месте; окружение можно завершить `deactivate`.

## Пример корректного результата

После dvc pull SHA-256 восстановленного CSV совпадает с исходным. После изменения хотя бы одного байта verify_restore поднимает ValueError. Автотесты проверяют хеш и содержимое, но не выполняют DVC-команды вместо тебя.
