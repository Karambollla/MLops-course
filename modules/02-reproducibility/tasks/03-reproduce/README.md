## Где работать и контракт

Редактируй `modules/02-reproducibility/tasks/03-reproduce/solution.py` (физическая заготовка рядом). Дополнительные тесты размещай в этой же папке. Полных решений в заготовке нет.

`compare_runs(first: Path, second: Path, batch) -> dict` читает manifest.json/split.json/metrics.json/model.joblib доверенных собственных запусков; проверяет одинаковые data_sha256, feature_order, seed, parameters и split (иначе ValueError), сравнивает pipeline.predict на batch и все MAE/RMSE с numpy.allclose(rtol=1e-6, atol=1e-8). Возвращает {"predictions_equal": bool, "metrics_equal": bool}; неверный порядок batch.columns — ValueError. Версии среды сравнивай по сохранённым зависимостям; не подменяй численную эквивалентность сравнением байтов. Сохрани environment freeze и точные команды восстановления в новой временной папке, фиксированные первые 20 строк batch, два набора метрик и отрицательные опыты SHA/features.

## Среда и зависимости

Базовая среда, numpy/pandas/joblib/sklearn; CPU.

Зависит от обоих предыдущих заданий и train. Автотесты изолируют процедуру сравнения; проверка на стенде требует именно нового окружения и реального обучения, а не копирования model.joblib.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=02-reproducibility/03-reproduce
```

До реализации ожидается RED: `NotImplementedError`, а не ошибка импорта зависимостей. После реализации все offline-тесты должны быть зелёными. Они создают временные данные через pytest tmp_path; полный housing автоматически не скачивается.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("02-reproducibility/03-reproduce")` из Python. CLI не требуется.

## Требования практического опыта

Сохрани окружение и команды так, чтобы новая временная директория получала те же данные, split и метрики в пределах допуска. Добавь отрицательную проверку: изменённый SHA-256 или другой порядок признаков не должен незаметно обслуживаться как прежняя модель.

## Приёмка и очистка

Выполни `test_task.py`: проверяются результаты функций, ошибки входа и изменения технических артефактов. Письменный пересказ выполнения не требуется.

Docker не требуется. Временные тестовые файлы убирает pytest. Сохрани необходимые CSV, split и модель для следующих модулей; окружение можно завершить `deactivate`. Учебные DVC demo/remote удаляй только после экспорта результатов.

## Пример корректного результата

Два эквивалентных запуска дают `{"predictions_equal": true, "metrics_equal": true}`. Изменённые прогнозы дают predictions_equal=false; другой SHA данных вызывает ValueError. Сравниваются числа с допуском, а не побайтовое равенство pickle.
