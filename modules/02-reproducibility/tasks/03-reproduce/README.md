# Восстановить эксперимент

[Практика модуля](../../practice.md) · [Теория](../../README.md) · [Подсказки](../../hints.md) · [SETUP](../../../../SETUP.md)

## Где работать и контракт

Редактируй `modules/02-reproducibility/tasks/03-reproduce/solution.py` (физическая заготовка рядом). Дополнительные свои тесты и `report.md` размещай в этой же папке. Полных решений в заготовке нет.

`compare_runs(first: Path, second: Path, batch) -> dict` читает manifest.json/split.json/metrics.json/model.joblib доверенных собственных запусков; проверяет одинаковые data_sha256, feature_order, seed, parameters и split (иначе ValueError), сравнивает pipeline.predict на batch и все MAE/RMSE с numpy.allclose(rtol=1e-6, atol=1e-8). Возвращает {"predictions_equal": bool, "metrics_equal": bool}; неверный порядок batch.columns — ValueError. Различия версий среды показывай в report.md, не подменяй численную эквивалентность сравнением байтов. Сохрани environment freeze и точные команды восстановления в новой временной папке, фиксированные первые 20 строк batch, два набора метрик и отрицательные опыты SHA/features.

## Среда и зависимости

Базовая среда, numpy/pandas/joblib/sklearn; CPU.

Зависит от обоих предыдущих заданий и train. Автотесты изолируют процедуру сравнения; ручная приёмка требует именно нового окружения и реального обучения, а не копирования model.joblib.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=02-reproducibility/03-reproduce
```

До реализации ожидается RED: `NotImplementedError`, а не ошибка импорта зависимостей. После реализации все offline-тесты должны быть зелёными. Они создают временные данные через pytest tmp_path; полный housing автоматически не скачивается.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("02-reproducibility/03-reproduce")` из Python. CLI не требуется.

## Требования практического опыта

Сохрани окружение и команды так, чтобы новая временная директория получала те же данные, split и метрики в пределах допуска. Добавь отрицательную проверку: изменённый SHA-256 или другой порядок признаков не должен незаметно обслуживаться как прежняя модель.

## Приёмка и очистка

Пройди все тесты `test_task.py`, сохрани перечисленные артефакты и добавь объяснение решений/ограничений в `report.md`. Для инфраструктурных опытов приложи реальные команды и вывод: offline проверки не доказывают развёртывание, доступность удалённого сервера или качество объяснения. Ручная оценка: воспроизводимость шагов, соответствие исходному контракту, объяснение причины сбоя и корректное восстановление.

Docker не требуется. Временные тестовые файлы убирает pytest. Сохрани CSV, split, отчёты и модель в `work/` для следующих модулей; окружение можно завершить `deactivate`. Учебные DVC demo/remote удаляй только после экспорта результатов.
