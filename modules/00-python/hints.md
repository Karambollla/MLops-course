# Подсказки: Python для Go-разработчика

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Сначала отфильтруй значения, затем вычисляй среднее. Иначе знаменатель может учитывать отклонённые записи.
2. `isinstance(True, int)` возвращает `True`. Добавь явное исключение для булевых значений.
3. Конечность проверяет `math.isfinite`. NaN не равен самому себе, поэтому обычное сравнение на равенство здесь не помогает.
4. Для нумерации JSONL используй `enumerate(stream, start=1)`. Ошибку JSON поймай отдельно от ошибки открытия файла.
5. При проверке мутации сохрани копию входа и сравни после вызова. Для вложенных объектов помни о глубине копирования.
