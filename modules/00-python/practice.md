## Подготовка

Основная среда из [SETUP](../../SETUP.md). Заготовка: `labs/python/records.py`. Стендов Docker нет.

## Задание 1. Обработка записей

Реализуй `summarize(records)` со следующим контрактом: принимает список словарей, учитывает только конечные положительные значения `duration` типа `int` или `float`, исключая `bool`. Возвращает `{"count": N, "mean": value}`; для пустой выборки среднее равно `None`. Вход не изменяется.

```bash
python -m unittest discover -s labs/python -p 'test_*.py' -v
```

До реализации ожидается ошибка `NotImplementedError`; после — зелёные тесты. Добавь проверки NaN, бесконечности и отсутствия мутации. Артефакт: код, тесты и короткое объяснение `bool`/`int`.

## Задание 2. JSONL и ошибки

Добавь отдельный CLI, который читает JSONL построчно и использует функцию из задания 1. Повреждённая JSON-строка должна завершать CLI с ненулевым кодом и номером строки; неверное поле `duration` обрабатывается по контракту функции. Сравни поведение файла из трёх корректных строк и файла с повреждённой второй строкой. Не загружай весь файл в память.

## Задание 3. Табличные данные

После скачивания housing.csv выведи shape, dtype, число пропусков и квантили каждого столбца. Сохрани вывод в `work/python-summary.md`. Покажи пример расхождения индексов двух Series и исправь его. Не используй target в качестве признака.

## Критерии готовности

- [ ] Все тесты задания 1 проходят; неверные записи не портят среднее.
- [ ] CLI сообщает номер повреждённой строки и код ошибки.
- [ ] Объяснены ссылочная семантика, `None`, генератор, shape и блокировка event loop.

## Завершение

Окружение можно деактивировать командой `deactivate`. Учебные отчёты остаются в `work/`; удаление этой папки не требуется.
