## Цель и необходимые знания

Уметь читать и писать небольшой Python-пакет, обрабатывать табличные данные и проверять поведение тестами. Нужны навыки программирования на Go; опыт Python не предполагается.

Практическая проблема знакома по backend: есть поток записей с длительностями, из него нужно получить корректную сводку и вернуть понятную ошибку вызывающему процессу. Затем вместо отдельных записей появится CSV, из которого будет обучаться модель. Если перепутать отсутствие значения с нулём, принять `True` за число или соединить строки по позиции, программа может успешно завершиться и сохранить неправильный результат. Поэтому здесь сначала строится граница данных, а уже потом ML.

Из [SETUP](../../SETUP.md) нужны установленный пакет `housing`, Python 3.12 и pytest. Предыдущих учебных артефактов пока нет. В [первой теме](tasks/01-records/README.md) появится чистая функция, во [второй](tasks/02-jsonl-cli/README.md) — читающий её CLI, в [третьей](tasks/03-tabular-analysis/README.md) — вычисляемая сводка таблицы `work/python-summary.md`. «Чистая» здесь означает, что функция не меняет переданный список и не пишет файлы; результат зависит от входных записей.

## От записи к результату

Словарь `{"duration": 2.0}` играет роль небольшой Go-структуры, но не гарантирует наличие и тип поля. Запись `{}` допустима как Python-объект, хотя значения `duration` в ней нет. В упражнении такую запись пропускают; повреждённый JSON во втором упражнении, напротив, прерывает весь файл. Это два разных уровня проверки: синтаксис формата и пригодность поля для расчёта.

Для входа `[{"duration": 2}, {"duration": 4}, {"duration": True}]` первые два значения проходят правило «конечное положительное число», третье исключается. Сумма равна 6, количество — 2, среднее — 3.0. Пустая пригодная выборка даёт `mean=None`, поскольку ноль означал бы измеренное среднее, которого здесь нет. При сериализации в JSON `None` становится `null`, а Python `True` — JSON `true`; написание из одного языка нельзя механически вставить в другой.

Конечность означает отсутствие NaN и положительной/отрицательной бесконечности. NaN обозначает неопределённый числовой результат и ведёт себя необычно: `float("nan") == float("nan")` ложно. Проверка только `value > 0` отсеет NaN, но пропустит положительную бесконечность. Для числовой границы понадобится отдельная проверка конечности. Аннотация `float` не выполняет её автоматически.

## Имена, объекты и типы

В Go тип переменной фиксируется компилятором. В Python имя связывается с объектом во время выполнения; аннотация `list[float]` помогает редактору и статическому анализатору, но сама не проверяет вход. Проверка данных на HTTP-границе и аннотации решают разные задачи.

Присваивание списка не копирует его. После `b = a` оба имени указывают на один изменяемый объект. `a.copy()` копирует только верхний уровень: вложенные словари остаются общими. Это важно для конфигураций эксперимента: изменение одной вложенной настройки может неожиданно затронуть другой запуск. Для независимого варианта используй явное построение конфигурации или осознанную глубокую копию.

`None` означает отсутствие значения. Пустой список, ноль и `None` ложны в условии, поэтому `if not value` подходит не для всех проверок. Если ноль допустим, проверяй `value is None`. `bool` является подтипом `int`: при проверке числового поля отдельно реши, допустимы ли `True` и `False`.

## Коллекции и вычисления

`list` — последовательность, `tuple` — неизменяемая последовательность, `dict` — отображение, `set` — множество. List comprehension удобен для короткого преобразования; длинную логику с несколькими исключениями лучше вынести в функцию. Генератор вычисляет элементы по мере чтения, поэтому подходит для JSONL-файла, который не помещается в память.

```python
from collections.abc import Iterable

def positive_values(values: Iterable[float]) -> list[float]:
    return [value for value in values if value > 0]
```

NumPy — библиотека числовых массивов, pandas — библиотека таблиц и помеченных рядов. Массив NumPy имеет форму (размеры по осям) и dtype (тип хранения элементов). Операция над массивом обычно выполняется внутри скомпилированного кода; цикл Python по миллиону строк может быть существенно медленнее. Но векторизация не отменяет стоимость памяти: промежуточный массив может быть размером с исходный. В pandas различай отбор строк через `.loc` и позиционный `.iloc`; индексы участвуют в выравнивании Series. После перемешивания данных случайное выравнивание по индексам способно испортить обучающую выборку без исключения.

## Функции, исключения и ресурсы

Ожидаемые ошибки входа обрабатывай рядом с границей. Не оборачивай весь train-скрипт в `except Exception: pass`: пайплайн обязан сообщить о неуспехе кодом завершения. `ValueError` подходит для неверного значения, `TypeError` — для неподходящего типа. В собственных функциях выбирай контракт заранее: пропустить невалидную запись или остановить обработку.

```python
import json
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    path = Path(folder) / "config.json"
    path.write_text('{"seed": 42}', encoding="utf-8")
    with path.open(encoding="utf-8") as stream:
        config = json.load(stream)
    print(config["seed"])  # 42
```

Пример сам создаёт маленький вход, читает его и проверяется выводом 42. Внешний контекст убирает временную папку, внутренний закрывает файл даже при ошибке чтения. Для настоящего CSV путь приходит из аргумента программы; автоматически удалять исходные данные, как временную папку примера, не нужно.

`with` напоминает управление ресурсами через `defer`, но привязан к блоку. Аргумент функции вида `items=[]` создаётся один раз при определении функции. Для нового списка на каждый вызов используй `None` и создание списка внутри.

## Пакет и окружение

`venv` изолирует зависимости, а `pyproject.toml` описывает пакет. Команда `python -m package.module` запускает модуль через текущий интерпретатор и помогает избежать путаницы с PATH. Версии прямых зависимостей и lock транзитивных зависимостей отвечают за повторяемую установку. Контейнер дополнительно фиксирует системное окружение.

Тест проверяет поведение, а не внутреннее число вызовов функции. В упражнении нужны пустой ввод, корректные записи, неверные типы и отрицательные значения. Отдельно проверь, что функция не меняет исходный список.

В Go обычно строят бинарник с выбранным `go.mod`; здесь запускают интерпретатор, который ищет пакет в своём окружении. `python -m pip ...` привязывает установщик к тому же Python, которым затем выполняется код. Установка `housing` с `-e` делает исходники доступными как пакет без копирования каждой правки; `--no-deps` в инструкции курса означает, что зависимости уже установлены из закреплённого requirements. Это не команда для пропуска необходимых библиотек в пустой среде.

Упражнения загружаются через `course_tasks.load_task("00-python/01-records")`: каталог с дефисом не является обычным именем Python-модуля, поэтому курс даёт загрузчик. Он находит `solution.py`, но не подменяет его реализацию. `NotImplementedError` из этого файла означает, что заготовка найдена. `ModuleNotFoundError: course_tasks` означает другую проблему — пакет не установлен в выбранный интерпретатор или команда выполняется в другом окружении.

## Построчное чтение и контракт CLI

**JSONL** (JSON Lines) — текстовый формат, где каждая строка содержит отдельное JSON-значение. В нашей задаче разрешены только JSON objects, превращающиеся в `dict`. `[]` является корректным JSON, но не записью нужного формата. Пустая строка тоже считается ошибкой. Номер строки считают от 1 по исходному файлу; пропуск пустых строк незаметно изменил бы диагностику.

**Итератор** отдаёт следующий элемент по запросу, а **генератор** позволяет описать такой итератор с `yield`. Создание генератора ещё не означает чтение всех строк. Ошибка второй строки проявится при запросе второй записи; до третьей чтение доходить не должно. Функция-агрегатор хранит сумму и количество, поэтому ей не нужен список всех записей. Дополнительная память зависит от размера одной строки, а не от размера всего файла. `list(iterator)` перед агрегацией отменит это свойство.

CLI — интерфейс командной строки. Его stdout — машинный результат, stderr — диагностика, код завершения — сигнал успешности для shell, CI и будущего Airflow. При повреждённой второй строке ожидаются сообщение с номером 2 в stderr, ненулевой код и отсутствие успешной сводки в stdout. Не печатай промежуточный JSON до полного завершения расчёта: потребитель может принять частичный результат за готовый. Ожидаемый `ValueError` на этой границе переводится в короткую диагностику без traceback; неожиданную ошибку программирования не следует маскировать как неверный файл.

## Таблица, индекс и форма массива

**DataFrame** в pandas — таблица с именами столбцов и метками строк; **Series** — один именованный набор значений с индексом. **Shape** — размеры, например `(4, 2)` означает четыре строки и два столбца. **Dtype** — тип хранения столбца: `float64` отличается от `object`, в котором могут оказаться строки и смешанные объекты. Наличие числа в CSV ещё не гарантирует числовой dtype после чтения: одна текстовая запись способна изменить тип столбца.

Индекс pandas — часть операции, а не декоративный номер. Разбери самостоятельный пример в основной среде:

```python
import pandas as pd

prices = pd.Series([20, 10], index=["b", "a"])
fees = pd.Series([1, 2], index=["a", "b"])
print((prices + fees).to_dict())       # {'a': 11, 'b': 22}
print(prices.to_numpy() + fees.to_numpy())  # [21 12]
```

В первом действии сопоставляются метки: цене `b=20` соответствует комиссия `b=2`. Во втором индекс потерян, поэтому складываются первые элементы, хотя они относятся к разным объектам. Оба результата числовые и без исключения; ошибка обнаруживается проверкой смысла меток. В задаче выравнивания нужны только общие метки и порядок левой Series. Это похоже на join по ключу в SQL; `reset_index` перед сложением превращает его в соединение по позиции и меняет смысл.

**Квантиль** делит упорядоченные значения: медиана, или квантиль 0.5, лежит посередине. Для `[1, 2, 3, NaN]` pandas исключает пропуск из расчёта, но считает его в `missing`. При линейной интерполяции квантиль 0.25 лежит между 1 и 2 и равна 1.5; 0.75 — 2.5. В сводке квантили нужны только для числовых столбцов; dtype и количество пропусков — для всех. Такой осмотр найдёт неожиданную строку, пропуск или масштаб до обучения.

В housing столбец `MedHouseVal` — известный ответ, **target**; остальные восемь столбцов — входные **признаки**. Target участвует в описании таблицы, но не должен попадать во вход модели. Иначе обучение получит ответ в составе вопроса. В модуле 01 эта ошибка будет разобрана как утечка данных.

## Как различать ошибки

| Наблюдение | Что проверить первым | Почему это важно |
|---|---|---|
| Среднее равно бесконечности | Конечность каждого принятого числа | Положительность не исключает Infinity |
| Один вызов изменил следующий | Общий список или изменяемый аргумент по умолчанию | Имена могут ссылаться на один объект |
| Ошибка JSON появляется слишком поздно | Нет ли `list(stream)` или чтения всего файла заранее | Ленивость проверяется порядком потребления |
| После сложения появились NaN | Совпадение индексов двух Series | pandas выравнивает метки, которых у другой стороны может не быть |
| CSV содержит `Unnamed: 0` | Не сохранён ли индекс через `to_csv` | Технический индекс не является признаком |

Зелёные маленькие тесты подтверждают правила функции на проверенных входах. Они не доказывают качество housing-данных и не заменяют просмотр вычисленной сводки. Для этой темы Docker и сетевые сервисы не нужны; загрузчик housing впервые требует сеть только при получении датасета.

## Конкурентность

Горутина и `asyncio`-задача не эквивалентны. `asyncio` требует неблокирующих операций: синхронное обучение модели внутри `async def` блокирует event loop. Для сетевого I/O подходят async-клиенты или потоки; для тяжёлого Python CPU-кода обычно рассматривают процессы или отдельные workers. NumPy и библиотеки ML могут освобождать GIL и запускать собственные потоки, поэтому увеличение числа workers без измерений способно привести к oversubscription.

Итоговый вопрос: если четыре HTTP-worker одновременно запускают обучение с восемью потоками, сколько вычислительной нагрузки получит ноутбук и где ограничить параллелизм?
