## Зачем описывать таблицу до обучения

CSV может читаться без исключения и всё равно оказаться неправильным входом: числовой столбец стал строковым, появился сохранённый индекс или потерялись значения. Вычисляемая сводка помогает обнаружить такие изменения до `fit`. Вторая часть защищает от более тихой ошибки — соединения признаков и ответов по разным строкам. Основа — [таблица и индекс pandas](../../README.md#таблица-индекс-и-форма-массива).

## Исходное состояние

Готовый загрузчик `housing.data` получает `work/housing.csv`; в нём восемь признаков района и известный ответ `MedHouseVal`. Функции анализа в `solution.py` ещё не реализованы, зато `test_task.py` использует маленькую таблицу, поэтому для проверки функций скачивание housing не нужно. Добавь вычисление сводки, выравнивание двух Series и сохранение вычисленного Markdown. Этот файл — результат анализа данных, его не нужно дополнять ручным рассказом.

Для Series `left={b:20,a:10,c:30}` и `right={a:1,b:2,d:9}` общие метки — `b,a` в порядке левой стороны. После выравнивания пары равны `(20,2)` и `(10,1)`, суммы — 22 и 11. Позиционное сложение дало бы 21 и 12 и прошло бы без исключения. Проверь именно метки и числа, а не только длину. Для сводки `[1,2,3,NaN]` проверь одновременно один пропуск и медиану 2: пропуски описываются отдельно от расчёта квантилей.

## Где работать и контракт

Редактируй `modules/00-python/tasks/03-tabular-analysis/solution.py`. Дополнительные тесты размещай в этой же папке.

`describe_frame(frame) -> dict` возвращает shape как список [rows, cols], dtypes и missing по всем столбцам, quantiles {column: {"0.25": value, "0.5": value, "0.75": value}} для числовых столбцов (pandas linear interpolation). `align_series(left, right) -> tuple` выравнивает Series по общим меткам через inner join с сохранением порядка левой Series; не сбрасывает индекс по позиции. `write_report(csv_path: Path, output: Path) -> None` пишет Markdown shape/dtypes/missing/quantiles. Target описывается, но никогда не передаётся как признак. Проверь ошибочное и исправленное сложение Series тестом с переставленными индексами.

## Пример корректного результата

Для числового столбца `[1, 2, 3, NaN]` число пропусков равно 1, квантили 0.25/0.5/0.75 равны 1.5/2.0/2.5. Для Series с индексами `[b,a,c]` и `[a,b,d]` общие строки должны идти в порядке `[b,a]`; сложение по позиции неверно.
