## Где работать и контракт

Редактируй `modules/00-python/tasks/03-tabular-analysis/solution.py` (физическая заготовка рядом). Дополнительные тесты размещай в этой же папке. Полных решений в заготовке нет.

`describe_frame(frame) -> dict` возвращает shape как список [rows, cols], dtypes и missing по всем столбцам, quantiles {column: {"0.25": value, "0.5": value, "0.75": value}} для числовых столбцов (pandas linear interpolation). `align_series(left, right) -> tuple` выравнивает Series по общим меткам через inner join с сохранением порядка левой Series; не сбрасывает индекс по позиции. `write_report(csv_path: Path, output: Path) -> None` пишет Markdown shape/dtypes/missing/quantiles. Target описывается, но никогда не передаётся как признак. Проверь ошибочное и исправленное сложение Series тестом с переставленными индексами.

## Среда и зависимости

Базовая среда, pandas; CPU.

Данные: python -m housing.data --output work/housing.csv. Вызови write_report для work/python-summary.md из Python. Зависит от загрузки данных; Docker не нужен.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=00-python/03-tabular-analysis
```

До реализации ожидается RED: `NotImplementedError`, а не ошибка импорта зависимостей. После реализации все offline-тесты должны быть зелёными. Они создают временные данные через pytest tmp_path; полный housing автоматически не скачивается.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("00-python/03-tabular-analysis")` из Python. CLI не требуется.

## Требования практического опыта

После скачивания housing.csv выведи shape, dtype, число пропусков и квантили каждого столбца. Сохрани вывод в `work/python-summary.md`. Покажи пример расхождения индексов двух Series и исправь его. Не используй target в качестве признака.

## Приёмка и очистка

Выполни `test_task.py`: проверяются результаты функций, ошибки входа и изменения технических артефактов. Письменный пересказ выполнения не требуется.

Docker не требуется. Временные тестовые файлы убирает pytest. Сохрани необходимые CSV, split и модель для следующих модулей; окружение можно завершить `deactivate`. Учебные DVC demo/remote удаляй только после экспорта результатов.

## Пример корректного результата

Для числового столбца `[1, 2, 3, NaN]` число пропусков равно 1, квантили 0.25/0.5/0.75 равны 1.5/2.0/2.5. Для Series с индексами `[b,a,c]` и `[a,b,d]` общие строки должны идти в порядке `[b,a]`; сложение по позиции неверно.
