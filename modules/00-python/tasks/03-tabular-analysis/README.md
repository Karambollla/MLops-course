# Сводка таблицы и выравнивание индексов

[Подготовка](../../README.md#подготовка-к-заданиям) · [Все задания](../../README.md#задания) · [Теория pandas](../../README.md#таблица-индекс-и-форма-массива)

## Задача

CSV может успешно читаться и при этом содержать неверные данные: числовой столбец стал строковым, появились пропуски или сохранился лишний индекс. Перед обучением нужна вычисляемая сводка структуры таблицы. Отдельно нужно проверить, что значения двух Series сопоставляются по меткам индекса. Совпадение длины массивов не гарантирует, что строки описывают одни и те же объекты.

## Что подготовлено

В [solution.py](solution.py) находятся три заготовки и импорты pandas и `Path`. [Тесты](test_task.py) используют маленькие синтетические таблицы. Для ручного опыта есть загрузчик `housing.data`, который сохраняет CSV California Housing: восемь признаков района и целевой столбец `MedHouseVal`.

## Подготовка

Используй основное окружение по [инструкции модуля](../../README.md#подготовка-к-заданиям). Маленькие тесты работают без сети и Docker. Реальный CSV потребуется только для заключительного вызова `write_report`.

## Что реализовать

### `describe_frame`: описать таблицу

```python
def describe_frame(frame) -> dict:
    ...
```

| Аргумент | Тип и формат | Происхождение и назначение | Пример |
|---|---|---|---|
| `frame` | `pandas.DataFrame` с числовыми и текстовыми столбцами | Таблица из теста или результат `pd.read_csv`. Нужно описать все её столбцы | `pd.DataFrame({"x": [1.0, 2.0, 3.0, float("nan")], "label": ["a", "b", None, "c"]})` |

Верни словарь следующего содержания:

| Поле | Формат и смысл |
|---|---|
| `shape` | Список `[число строк, число столбцов]` |
| `dtypes` | Словарь `{имя столбца: строковое представление dtype}` для всех столбцов |
| `missing` | Словарь `{имя столбца: число пропусков}` для всех столбцов |
| `quantiles` | Только числовые столбцы. Для каждого словарь с ключами `"0.25"`, `"0.5"`, `"0.75"` |

Для приведённой таблицы `shape` равен `[4, 2]`, тип `x` — `"float64"`, пропусков в `x` и `label` по одному. Для `x` квантили равны `1.5`, `2.0`, `2.5`. Используется линейная интерполяция pandas, пропуски в расчёт квантилей не входят. У текстового столбца нет квантилей. Если числовых столбцов нет, `quantiles` равен `{}`.

### `align_series`: сопоставить строки

```python
def align_series(left, right) -> tuple:
    ...
```

| Аргумент | Тип и формат | Происхождение и назначение | Пример |
|---|---|---|---|
| `left` | `pandas.Series` с индексом | Левая последовательность задаёт порядок общих меток в результате | Значения `[20, 10, 30]`, индекс `["b", "a", "c"]` |
| `right` | `pandas.Series` с индексом | Правая последовательность сопоставляется с левой по меткам | Значения `[1, 2, 9]`, индекс `["a", "b", "d"]` |

Верни пару Series, оставив только общие метки — аналог inner join. Обе Series должны иметь одинаковый индекс в порядке левой стороны. В примере получится индекс `["b", "a"]`, значения слева `[20, 10]`, справа `[2, 1]`. Сумма равна `[22, 11]`.

Сбрасывать индекс и складывать по позиции нельзя: это дало бы `[21, 12]`. Если общих меток нет, верни две пустые Series. При частичном пересечении не добавляй отсутствующие строки и не сортируй метки независимо от левого порядка.

### `write_report`: сохранить вычисленную сводку

```python
def write_report(csv_path: Path, output: Path) -> None:
    ...
```

| Аргумент | Тип и формат | Происхождение и назначение | Пример |
|---|---|---|---|
| `csv_path` | `pathlib.Path` к существующему CSV | Исходная таблица, которую нужно прочитать через pandas | `Path("work/housing.csv")` |
| `output` | `pathlib.Path` к результирующему Markdown-файлу | Выбранный путь для вычисленной сводки. Родительские каталоги могут ещё не существовать | `Path("work/python-summary.md")` |

Прочитай CSV, вычисли сводку и запиши её в Markdown. В файле должны быть shape, dtypes, число пропусков и квантили. Создай недостающие родительские папки. Функция возвращает `None`. Это программно сформированный результат анализа данных, ручной рассказ о выполненной работе не нужен.

`MedHouseVal` тоже входит в описательную сводку CSV. При последующем обучении он становится целевой переменной и не должен попадать в признаки.

Открой полученный файл и сопоставь число строк, столбцов и их имена с CSV. В сводке должны быть восемь признаков и целевая переменная. Числа берутся из файла, их не нужно заменять значениями из примеров.
