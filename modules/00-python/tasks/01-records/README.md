# Обработка записей

[Практика модуля](../../practice.md) · [Теория](../../README.md) · [Подсказки](../../hints.md) · [SETUP](../../../../SETUP.md)

## Где работать и контракт

Редактируй `modules/00-python/tasks/01-records/solution.py` (физическая заготовка рядом). Дополнительные тесты размещай в этой же папке. Полных решений в заготовке нет.

`summarize(records: list[dict]) -> dict` принимает список словарей, учитывает только конечные положительные int/float duration, исключает bool; возвращает count и mean (None для пустой выборки). Не изменяет вход.

## Среда и зависимости

Базовая среда из SETUP: Python, pytest; CPU, Linux/macOS.

## Запуск и результат

Из корня репозитория:

```bash
make task TASK=00-python/01-records
```

До реализации ожидается RED: `NotImplementedError`, а не ошибка импорта зависимостей. После реализации все offline-тесты должны быть зелёными. Они создают временные данные через pytest tmp_path; полный housing автоматически не скачивается.

Это задание использует функции; импортируй заготовку через `course_tasks.load_task("00-python/01-records")` из Python. CLI не требуется.

## Требования практического опыта

Реализуй `summarize(records)` со следующим контрактом: принимает список словарей, учитывает только конечные положительные значения `duration` типа `int` или `float`, исключая `bool`. Возвращает `{"count": N, "mean": value}`; для пустой выборки среднее равно `None`. Вход не изменяется.

```bash
make task TASK=00-python/01-records
```

До реализации ожидается ошибка `NotImplementedError`; после — зелёные тесты. Добавь проверки NaN, бесконечности и отсутствия мутации. Результат проверяется кодом и тестами фильтрации `bool`/`int`.

## Приёмка и очистка

Выполни `test_task.py`: проверяются результаты функций, ошибки входа и изменения технических артефактов. Письменный пересказ выполнения не требуется.

Docker не требуется. Временные тестовые файлы убирает pytest. Сохрани необходимые CSV, split и модель для следующих модулей; окружение можно завершить `deactivate`. Учебные DVC demo/remote удаляй только после экспорта результатов.

## Пример корректного результата

Для `[{"duration": 2}, {"duration": 4}, {"duration": true}]` функция возвращает `{"count": 2, "mean": 3.0}`. Для пустого ввода — `{"count": 0, "mean": null}`. Это пример входа/выхода; полная реализация остаётся за тобой.
