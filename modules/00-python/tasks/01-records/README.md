# Обработка записей измерений

[Подготовка](../../README.md#подготовка-к-заданиям) · [Все задания](../../README.md#задания) · [Теория](../../README.md#от-записи-к-результату)

## Задача

Представь события backend-сервиса, у которых поле `duration` хранит длительность операции. Часть событий повреждена: поле отсутствует, содержит строку, отрицательное число или бесконечность. Требуется посчитать количество пригодных измерений и их среднее. Эта функция станет вычислительным ядром JSONL-программы следующего задания.

## Что реализовать

```python
def summarize(records: list[dict]) -> dict:
    ...
```

| Аргумент | Тип и формат | Откуда берётся и зачем нужен | Пример |
|---|---|---|---|
| `records` | Список словарей. В словаре может быть поле `duration` и любые дополнительные поля | Вызывающий код передаёт события, для которых нужно вычислить общую сводку | `[{"duration": 2}, {"duration": 4}, {"duration": True}]` |

Учитывай значение `duration`, только если оно имеет тип `int` или `float`, является конечным и строго больше нуля. `bool` исключается отдельно: в Python `isinstance(True, int)` возвращает `True`. Строку `"4"` не преобразовывай в число. Отсутствующее поле и неподходящее значение означают пропуск записи.

Вычисляй количество и сумму по одному и тому же набору пригодных измерений. Например, отклонённая запись не должна увеличивать знаменатель среднего. `math.isfinite` помогает отличить обычное число от `NaN` и бесконечности.

Входные словари и их вложенные поля должны остаться неизменными. Функция читает измерения, но не удаляет неподходящие записи из переданного списка и не заменяет значения полей.

В следующем задании источник записей станет ленивым итератором. Не привязывай вычисление среднего к повторному проходу по входу: поток может читаться только один раз.

## Результат и примеры

Функция возвращает словарь с двумя полями:

| Поле | Значение |
|---|---|
| `count` | Количество пригодных значений `duration` |
| `mean` | Среднее пригодных значений. Если таких значений нет, возвращается `None` |

| Вход | Результат | Причина |
|---|---|---|
| `[{"duration": 2}, {"duration": 4}, {"duration": True}]` | `{"count": 2, "mean": 3.0}` | Булево значение исключено |
| `[{"duration": 1.5}, {"duration": 2.0}]` | `{"count": 2, "mean": 1.75}` | Дробная часть среднего сохраняется |
| `[{"duration": "4"}, {}, {"duration": 0}]` | `{"count": 0, "mean": None}` | Пригодных значений нет |
| `[]` | `{"count": 0, "mean": None}` | Пустой вход тоже имеет определённую сводку |

Некорректный `duration` отфильтровывается. Он не должен останавливать обработку остальных записей. При последующем выводе в JSON Python `None` превратится в JSON `null`.
