# Версия настоящих embeddings

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

Реализуй `make_manifest(model_id, revision, vectors, corpus_bytes)`: вернуть model_id, revision, dimension, count, corpus_sha256. Revision — сохранённый неизменяемый идентификатор; main/latest не принимаются. Векторы конечные, ненулевые, одинаковой размерности. Затем получи настоящие embeddings через FastEmbed на CPU, новую коллекцию и собственные qrels. Unit-тесты с маленькими массивами проверяют контракт, а не качество языковой модели.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

В том же отдельном окружении установи `fastembed==0.6.1`. Выбери `BAAI/bge-small-en-v1.5`, зафиксируй model ID и revision/cache snapshot. Сгенерируй embeddings корпуса и запросов на CPU, определи размерность по фактическому выходу и создай новую коллекцию. Затем расширь собственный корпус до 30 документов и разметь 20 запросов. Сравни keyword baseline и vector search по одним qrels, не меняя разметку ради результата.

## Проверка

```bash
make task TASK=13-qdrant/03-embeddings
```

У этой задачи проверяются функции: запускай их тестами, отдельного CLI нет.

До реализации функции ожидается `NotImplementedError`. Реализуй заготовку, сохраняя контракт функций из тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.

## Результат

Функции должны проходить проверки положительных и отрицательных случаев. Для собственного эксперимента сохраняй исходные измерения в `work/`: они пригодятся для повторного сравнения. Отдельное письменное резюме не требуется. После работы останови стенд по инструкции practice.md.
