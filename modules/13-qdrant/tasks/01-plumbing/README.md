## С чего начать

В solution.py реализуй `build_points(documents)`: устойчивые уникальные integer IDs, vector из конечных чисел одинаковой ненулевой размерности, payload text/topic. Ошибочные или повторяющиеся IDs, нулевые/неконечные векторы и разные размерности — ValueError. Затем реализуй `index_documents(url, corpus_path)` и CLI main для реальной коллекции course-docs. Общий корпус и queries находятся в labs/search. Unit-тесты проверяют преобразование; live-проверка читает подготовленную тобой коллекцию.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Реализуй `modules/13-qdrant/tasks/01-plumbing/solution.py`: коллекция `course-docs`, размерность 4, cosine, устойчивые integer IDs. Загрузи корпус и выполни запросы из `labs/search/queries.json` через `query_points`. Повторная загрузка сохраняет ровно 8 points. Проверь фильтр topic=security и ошибку неверной размерности.

## Проверка

```bash
make task TASK=13-qdrant/01-plumbing
```

Для Python CLI:

```bash
python scripts/run_task.py run 13-qdrant/01-plumbing -- --help
```

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.
