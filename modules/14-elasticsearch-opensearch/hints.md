# Подсказки: Elasticsearch и OpenSearch: сравнение поиска

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Bulk требует Content-Type application/x-ndjson и последнюю пустую строку. Статус HTTP — только первый уровень проверки.
2. В OpenSearch vector field использует dimension, в Elasticsearch — dims. Запросы тоже различаются.
3. Повторная загрузка с новым случайным ID увеличивает индекс; используй corpus ID как _id.
4. RRF складывает ранги, а не scores. Начни с ручного примера из двух коротких списков.
5. Не меняй query embeddings между движками: тогда сравнение теряет смысл.
