# Сравнение и RRF

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

Реализуй `reciprocal_rank_fusion(rankings, constant=60) -> list[dict]`: записи {id, score} по убыванию суммы 1/(constant+rank). Rank начинается с 1; повтор ID в одном списке учитывается только на первой позиции. При одинаковом score сохраняется порядок первого появления в исходных списках. Отрицательная constant — ValueError. Сравнение качества выполняй по независимым qrels из модуля 13; одинаковые embeddings и candidate pool обязательны.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Сделай client-side RRF с c=60. Сравни keyword/vector/hybrid по Recall@2 и MRR на одинаковых qrels. Затем повтори на настоящих embeddings из модуля 13 с новой размерностью индексов. Не считай toy-векторы результатом обучения модели.

## Проверка

У этой задачи проверяются функции: запускай их тестами, отдельного CLI нет.

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.
