# Подсказки: Prometheus, Grafana и качество модели

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. В datasource URL должен быть `http://prometheus:9090`, а в scrape target — `api:8000`. Localhost внутри контейнера указывает на него самого.
2. Генерируй трафик именно на /predict. Scrape /metrics тоже увеличивает общий counter; исключай его из бизнес-RPS.
3. Rate требует нескольких samples. Подожди больше одного scrape interval и не делай вывод по первому пустому графику.
4. После stop api наблюдай Alerts, а не только dashboard: условие должно держаться весь for-период.
5. Для качества совмести prediction и target по устойчивому row ID, а не по текущему порядку строк.
