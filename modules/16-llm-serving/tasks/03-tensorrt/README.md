# TensorRT-LLM: маршрут самостоятельного эксперимента

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

Дополнительный материал для совместимого NVIDIA-стенда. Без GPU достаточно изучить последовательность и ожидаемые свойства результата; обязательного отчёта или JSON для заполнения нет. Автоматического зачёта по декларациям о запуске здесь нет.

## Подготовка и выполнение

```bash
nvidia-smi
bash labs/llm/tensorrt-llm.sh
```

Вторая команда открывает контейнер закреплённого backend 25.06; она не создаёт готовую модель. По [архивной инструкции 25.06](https://docs.nvidia.com/deeplearning/triton-inference-server/archives/triton-inference-server-2560/user-guide/docs/tensorrtllm_backend/README.html) выбери поддерживаемую модель, conversion script и параметры build для своего GPU. Подготовь weights из закреплённого snapshot, выполни conversion/build и настрой model repository как описано для этой модели. Маленькая модель из vLLM-упражнения может не поддерживаться. Команды новых релизов нельзя механически переносить в 25.06.

После собственного запуска Triton:

```bash
curl -f http://localhost:8000/v2/health/ready
curl -f http://localhost:8000/v2/models/tensorrt_llm/ready
curl -f http://localhost:8000/v2/models/tensorrt_llm/config
```

Имя `tensorrt_llm` относится к типичному repository из инструкции; при другом имени замени его. Успешные readiness дают HTTP 200; config содержит backend `tensorrtllm`. Это ожидаемые инварианты, не вывод реально выполненного в курсе GPU-запуска.

Для inference используй клиент и tensor names из выбранного примера 25.06: одного универсального тела запроса для разных ensemble/configuration нет. Успех — завершившийся запрос с непустым сгенерированным output, корректными shapes и без backend errors. Readiness сама по себе не доказывает inference.

## Что полезно сохранить

Для повторения эксперимента сохраняй фактические команды, model revision, GPU/driver/runtime, build flags, конфигурацию и checksum созданного engine рядом с исходными измерениями в `work/`. Эти данные относятся к артефактам эксперимента, не к обязательному письменному резюме. Engine может зависеть от GPU и версии TensorRT; файл из другого стенда не гарантирует совместимость.

Сравнивать скорость с vLLM/SGLang имеет смысл на той же модели, tokenizer и workload. Если модель несовместима с выбранным релизом, фиксированного коэффициента ускорения ожидать нельзя. Изучение команд без GPU не является измерением производительности. После работы останови запущенный вручную стенд.
