# TensorRT-LLM: собственный engine

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

Заполни engine-report.json собственными результатами preparation/build/inference. Нужны release25.06, поддерживаемая модель, immutable revision, GPU/driver, engine_sha256, команды и фактический inference. `solution.py` лишь выводит отчёт; реализовывать grader не требуется. Короткий bash из labs открывает среду, но не является готовой выкладкой.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **nvidia**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Скрипт `bash labs/llm/tensorrt-llm.sh` открывает контейнер закреплённого backend, но не запускает готовую модель. По архивной документации 25.06 выбери поддерживаемую модель и выполни preparation/build/configuration для своего GPU. Маленькая модель предыдущего упражнения может не поддерживаться этим релизом. Запиши точные команды, engine metadata и успешный inference. Не сравнивай разные модели как доказательство скорости движков.

## Проверка

```bash
make task TASK=16-llm-serving/03-tensorrt
```

Для Python CLI:

```bash
python scripts/run_task.py run 16-llm-serving/03-tensorrt -- --help
```

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.

## Критерии и завершение

Ручная рубрика: выбранная модель поддерживается именно релизом 25.06; engine построен для указанного GPU; hash соответствует файлу; приведён реальный успешный запрос; сравнение с другими engines выполнено на одной модели. На Mac без NVIDIA задача остаётся дополнительной и незачтённой; это ожидаемый аппаратный предел.
