# Память, SSE и корпус запросов

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

В solution.py реализуй `weights_bytes(parameters, bytes_per_parameter=2)` и `kv_cache_bytes(layers, kv_heads, head_dim, context, concurrency, bytes_per_element=2)`. Все значения — положительные int без bool. Формула KV дана в теории; накладные buffers в неё не входят. `sse_contents(lines)` возвращает непустые content chunks из строк data: JSON, игнорирует role/heartbeat/пустые строки, останавливается на [DONE]; событие error и повреждённый JSON — ValueError. Здесь каждая data-строка содержит один полный OpenAI JSON event. Корпус из 20 собственных prompts заполни в prompts.json; запуск LLM для этой задачи не нужен.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

1. Создай `work/llm-plan.md`: оцени веса FP16 для 0,5B и 7B, затем KV cache при layers=24, kv_heads=8, head_dim=64, context=2048 и FP16 для concurrency 1 и 8.
2. Изучи `labs/llm/request.json` и опиши обработку SSE: служебные chunks, первый непустой content, завершение, ошибка, отмена.
3. Подготовь корпус из 20 prompts с разными длинами и шаблон результатов benchmark.csv. Укажи, какие параметры нельзя сравнивать без GPU.

Для этих заданий не нужны платные API и фиктивный сервер.

## Проверка

```bash
make task TASK=16-llm-serving/01-memory-contract
```

У этой задачи проверяются функции: запускай их тестами, отдельного CLI нет.

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.
