[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

В answers.json запиши ответ на каждый из 12 вопросов, пример из собственного проекта и способ проверки. В answers.md собери устный рассказ. Тест проверяет заполнение всех 12 разных вопросов и наличие примера, но не правильность вывода. Ответ «не знаю» допустим для диагностики пробела, однако требует дальнейшей работы по ручной рубрике.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Ответь письменно, затем устно:

1. Как обнаружишь training-serving skew?
2. Почему random split может переоценить качество?
3. Как откатить модель, если image не менялся?
4. Что делать при failed task после успешной внешней публикации?
5. Почему up=1 не доказывает готовность?
6. Какие данные нужны для актуальной MAE?
7. Чем state Terraform отличается от Ansible inventory?
8. Как избежать секретов в MLflow artifacts?
9. Когда lexical поиск полезнее vector?
10. Что ограничивает concurrency LLM-serving?
11. Как организовать воспроизводимость на разных workers?
12. Какие компоненты проекта ты бы убрал для маленькой команды?

Для каждого ответа приведи пример или команду из собственной работы. Список терминов без связи с системой не засчитывается.

## Проверка

```bash
make task TASK=17-career/02-interview
```

Для Python CLI:

```bash
python scripts/run_task.py run 17-career/02-interview -- --help
```

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.

## Критерии и завершение

Ручная рубрика для каждого ответа: техническая правильность; собственное доказательство; объяснение компромисса. Сверь ответ с теорией и первоисточником, затем повтори без шпаргалки. Автоматически проверяется только полнота, не смысл текста.
