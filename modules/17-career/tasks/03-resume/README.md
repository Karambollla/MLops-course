# Резюме и карта пробелов

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

Заполни resume.md и portfolio.json: три собственных пункта, ссылки на доказательства, десять актуальных вакансий, навыки и три следующих шага. Для числового улучшения запиши baseline/candidate/percent/lower_is_better; тест проверит формулу процента. Для качественного пункта оставь comparison=null и приведи реальный артефакт. Автоматизация не проверяет правдивость резюме или актуальность рынка.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Создай три пункта резюме только с собственными числами. Составь таблицу: навык, доказательство, уровень самостоятельности, следующий шаг. После 10 вакансий выбери три наиболее важные темы продолжения. Отдельно отметь GPU и production-эксплуатацию, если они пока теоретические.

## Проверка

```bash
make task TASK=17-career/03-resume
```

Для Python CLI:

```bash
python scripts/run_task.py run 17-career/03-resume -- --help
```

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.

## Критерии и завершение

Ручная рубрика: каждый пункт правдив и связан с доступным доказательством; условия измерений указаны; учебный стенд назван учебным; теоретические GPU-навыки не представлены практическими. Для вакансий покажи дату просмотра и собственный анализ требований. Публиковать репозиторий или резюме тест не пытается.
