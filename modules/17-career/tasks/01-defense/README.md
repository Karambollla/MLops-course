# Защита собственного проекта

[Теория](../../README.md) · [Практика модуля](../../practice.md) · [Подсказки](../../hints.md)

## С чего начать

Заполни outline.md и defense.json: запись, длительность, разделы демонстрации и собственные проверки. Укажи путь к локальной записи в work или URL; автоматический тест не смотрит видео и не оценивает объяснение. solution.py выводит подготовленный план, а не создаёт ответы.

Подготовь [основное окружение](../../../../SETUP.md). Все команды ниже выполняются из корня курса. Платформа задания: **cpu**. Функции и ожидаемые результаты описаны также в `test_task.py`; тесты используют небольшие фиксированные данные.

## Исходное задание

Запиши 10-минутную демонстрацию по [гайду проекта](../../../../projects/capstone/README.md). Покажи predict, точную версию, rollout/rollback и искусственный отказ. Подготовь пять минут на вопросы без чтения шпаргалки.

## Проверка

```bash
make task TASK=17-career/01-defense
```

Для Python CLI:

```bash
python scripts/run_task.py run 17-career/01-defense -- --help
```

До реализации функции ожидается `NotImplementedError`; для отчётов — ошибка незаполненного поля. Исправляй заготовку или собственный результат, сохраняя ожидаемое поведение тестов. Офлайн-тест не подтверждает действия на внешнем стенде: проверки, требующие работающего сервиса, включаются явно через `MLOPS_RUN_INTEGRATION=1`.

## Критерии и завершение

Ручная рубрика: другой человек воспроизводит проект; baseline и кандидат сравнимы; версия явно показана; rollback проверен прогнозом; объяснения укладываются примерно в 10 минут и содержат ограничения. Успех теста схемы не означает успешную защиту. Сохраняй видео в work, а не в Git.
