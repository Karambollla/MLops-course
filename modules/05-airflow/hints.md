# Подсказки: Airflow: оркестрация ML-пайплайнов

[Вернуться к заданиям](practice.md)

Открывай следующий пункт только после собственной попытки.

1. Ошибки импорта проверь до trigger. Наличие файла в папке не означает, что scheduler смог его разобрать.
2. Вызывай `/opt/housing-venv/bin/python -m housing.train` через subprocess с массивом аргументов и `check=True`. ML-окружение отделено от зависимостей Airflow; не импортируй sklearn в scheduler.
3. Общий `/work` допустим для этой лабораторной. Для нескольких workers потребуется доступное всем хранилище.
4. Ключ на основе только времени запуска не помогает дедупликации. Включи версии входов и конфигурации.
5. Делай gate отдельным шагом: упавшая оценка не должна оставлять активный указатель на новую модель.
