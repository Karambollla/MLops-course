## Практика

Платформа и подготовка; начальное состояние; задача и точный контракт; команды проверки; ожидаемый позитивный и негативный результат; технические артефакты; остановка и сохранение данных.

Для функций используй поведенческие тесты с позитивными и негативными входами. Для инфраструктуры — явно включаемые read-only проверки подготовленного стенда. Если автоматизация непрактична, добавь воспроизводимые команды и пример корректного вывода. Не требуй пересказа действий и не проверяй заполненность текста. Концептуальная тема оформляется руководством без test_task.py.
