Тесты Python проверяют фильтрацию bool/NaN/Infinity, отсутствие мутации, потоковое чтение JSONL, ошибку с номером строки и сохранение порядка индексов при выравнивании Series. Временный эталон подтвердил выполнимость контрактов; готовые решения в курс не включены.

## Контейнеры после переноса

Заново собраны housing и Airflow. Проверки использовали отдельные Compose-проекты `mlops-check-*`, временные fixtures и синтетическую sklearn-модель. Обучение учащегося не подменялось решением.

| Стенд | Подтверждено |
|---|---|
| Housing | Корневой build context; загрузка файлов из /course/modules; live=200 и ready/predict=503 без модели; predict=200 с временной моделью; 422 на неверный вход и NaN/Infinity; совпадение с нативным Pipeline; UID 10001; read-only mount; сохранность после restart |
| Python в housing | 6 готовых HTTP-тестов прошли, 2 учебных пропущены |
| Airflow | Сборка; отдельный ML venv; UI; DAG из новой папки импортируется без ошибок; unpause/trigger; validate_data=success; обучение доходит до ожидаемого NotImplementedError; история переживает restart |
| Prometheus/Grafana | Scrape, datasource и dashboard; метрика 20 запросов; alert переходит в firing при остановке API и снимается после восстановления |

При первой сборке Airflow установка исходников от пользователя airflow упёрлась в root-owned egg-info. Исправление: один wheel собирается заранее и устанавливается в оба окружения без изменения прав исходников. После исправления сборка и runtime-проверка прошли.

Оповещение в этом запуске обнаружено примерно через **39 секунд** после остановки API; это наблюдение функциональной проверки. Машинные статусы — в [JSON](task-layout-checks.json). Предыдущие проверки остальных сервисов сохранены в [Docker-отчёте](docker-verification.md); повторно запускались затронутые стенды.

## Что остаётся самостоятельной практикой

Выполнение обучения, gate/publish, настройка инфраструктуры и собственные измерения выполняются учащимся. Проверка схемы отчёта не доказывает истинность измерений; для этого в README заданий есть ручные критерии и требования к командам/выводам.

NVIDIA GPU и дополнительные Linux x86_64-маршруты не использовались. Новые GPU-тесты и шаблоны не означают выполненный бенчмарк. Удалённый GitHub Actions после этого изменения не запускался.

После проверок созданные контейнеры и volumes удалены. Пользовательский work и Terraform state не изменены; базовые образы и build cache сохранены. Итоговую проверку изменения выполнил основной агент; дополнительный независимый обзор этого переноса не был завершён из-за лимита сервиса агентов.

## Повторение локальных проверок

После [SETUP](../SETUP.md), из корня:

```bash
make check test tasks-collect
make task-list
make task TASK=00-python/02-jsonl-cli
```

Последняя команда ожидаемо падает до выполнения задания. `make tasks` запускает все учебные проверки, включая отчёты дополнительных платформ.
