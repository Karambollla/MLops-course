# Независимый обзор и исправления

Дата: 2026-10-31. Выполнен обзор свежим агентом с отдельным контекстом: спецификация, все практические инструкции, основные конфигурации и контракты. Критических замечаний не выявлено.

## Исправленные замечания

| Замечание | Исправление | Проверка |
|---|---|---|
| `make check` ломался после Terraform init | Исключены `.terraform`, окружения и служебные каталоги в сканерах | Реальная ошибка воспроизведена на скачанном provider; после исправления проверка проходит при сохранённом cache |
| Новый Airflow DAG оставался paused | Добавлены unpause и list-runs, пояснены queued/running/failed | Синтаксис сверён с документацией Airflow 3.1.0; контейнерный запуск не выполнен |
| Не было перехода offline ClearML → UI/Agent | Добавлен явный online-run, endpoints и отключение offline при работе Agent | Проверены инструкция, SDK API и синтаксис; полноценный Agent не запускался |
| Uvicorn занимал порт перед Compose | Добавлена остановка перед сборкой/запуском стенда | Последовательность шагов просмотрена |
| Комментарий ссылался на отсутствующий vectors.json | Указаны реальные corpus.json и queries.json | Проверено наличие файлов |

Первые три пункта оценены как существенные для прохождения курса. Последние два исправлены вместе с ними, поскольку влияли на точность инструкции и навигации.

## Границы обзора

Учебные `NotImplementedError` оставлены намеренно: пользователь реализует задания самостоятельно. Контейнерный/GPU runtime не подтверждён при остановленном Docker daemon. Production HA/TLS и облачная инфраструктура остаются за пределами обязательного ноутбучного курса. Toy-примеры проверяют интерфейсы, а не доказывают качество модели или производительность на реальных нагрузках.

После исправлений повторный независимый обзор не выполнялся; доступные проверки повторены автором и перечислены в [отчёте](verification.md).
