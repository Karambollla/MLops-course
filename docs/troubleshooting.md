# Диагностика проблем

## Общий порядок

Зафиксируй команду, версии, последнюю успешную операцию и полный текст ошибки. Проверь свободные ресурсы, сетевую доступность и конфигурацию. Меняй по одной причине, затем повторяй исходную проверку.

| Симптом | Что проверить | Ожидаемое действие |
|---|---|---|
| Permission denied к Docker socket | `docker version`, выбранный context, Docker runtime | Запустить runtime; при ограничении среды выполнить в собственном терминале |
| No matching manifest | Архитектуру image через `docker buildx imagetools inspect IMAGE:TAG` | Использовать совместимый образ или пометить лабораторную как требующую другой среды |
| Контейнер перезапускается | `docker compose ... logs`, `docker stats --no-stream` | Отличить нехватку RAM от неверного config |
| Порт уже занят | `lsof -i :PORT` | Остановить свой предыдущий стенд или изменить только host port |
| API возвращает 503 | Есть ли обученный артефакт, `MODEL_PATH`, startup logs | Завершить обучение и проверить путь/формат |
| Kubernetes ImagePullBackOff | Тег, imagePullPolicy, `kind load docker-image` | Загрузить нужный локальный тег |
| Kubernetes Pending | `kubectl describe pod`, requests, node resources | Освободить память или уменьшить учебный стенд |
| MLflow не видит артефакт | Tracking URI, путь, права volume | Различить путь на клиенте и путь внутри server |
| Airflow не видит DAG | Import errors, mount, часовой пояс, paused state | Проверить `airflow dags list-import-errors` |
| OpenSearch падает при старте | Логи и `vm.max_map_count` Linux VM | Следовать настройке VM; не менять случайные параметры macOS |
| Метрик нет | `/metrics`, target status и адрес scrape | Внутри Compose использовать имя сервиса |

## Чего избегать

Не удаляй все volumes, не меняй несколько версий одновременно и не добавляй `--platform linux/amd64` ко всем образам наугад. Эмуляция архитектуры может быть медленной и не добавляет CUDA-поддержку. Секреты не прикладывай к отчётам; показывай названия переменных и маскированные значения.

## Доказательство исправления

Сохрани исходный симптом, проверенную гипотезу и ту же команду после исправления. Если запуск не состоялся из-за оборудования или политики среды, так и напиши. Отдельно выполни доступную статическую проверку, не выдавая её за runtime-проверку.
