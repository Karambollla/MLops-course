# Спецификация курса «Из Go backend в MLOps»

Согласовано в разговоре 2026-10-31. Создать полный русскоязычный курс для Go backend-разработчика с базовыми знаниями ML, Linux, Docker и CI/CD. Цель — самостоятельное сопровождение ML-сервиса и подготовка доказуемого проекта для портфолио.

Обязательны 18 модулей, теория, примеры, задания с проверяемыми результатами, подсказки, первоисточники, минимальные стартовые файлы. Полные решения упражнений не включаются. Все инструменты знакомого покрываются: Airflow, MLflow, ClearML, Elasticsearch, OpenSearch, Qdrant, Prometheus, Grafana, Triton, TensorRT-LLM, vLLM, SGLang, Kubernetes, Helm, Vault, Terraform, Ansible и Python/ML.

Среда: Mac ARM64, 16 ГБ RAM, без NVIDIA GPU. Обязательная практика бесплатна и выполняется на CPU; тяжёлые стенды запускаются последовательно. GPU-практика вынесена в дополнительный маршрут с честной маркировкой статуса запуска.

Выбран подход «полный курс + интенсив», а не краткий обзор или равное время на каждый инструмент. Интенсив: 14 дней по 6–8 часов; сокращённый вариант: 7 дней только по основному проекту. Полное освоение всего стека и оффер за этот срок не обещаются.

Основной проект: прогноз стоимости жилья California Housing, Python/FastAPI, воспроизводимость, MLflow/Airflow, Docker/Kubernetes/Helm, CI и мониторинг с откатом. Поиск по документации — отдельное расширение. ClearML и альтернативные serving/search инструменты не встраиваются искусственно в один сервис.

Приёмка: читаемые Markdown-файлы без битых внутренних ссылок, проверяемые задания, закреплённые версии, доступные статические и runtime-проверки, отчёт с явными ограничениями. Структура утверждена пользователем перед реализацией.
