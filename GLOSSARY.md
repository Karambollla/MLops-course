# Словарь курса

| Термин | Значение |
|---|---|
| Artifact | Сохраняемый результат программы: модель, метрики, график или разбиение данных. Например, `model.joblib` читает сервис предсказаний. Не каждый артефакт является моделью, готовой к выпуску. |
| Baseline | Простое исходное решение, с которым сравнивают кандидата. Например, модель, всегда предсказывающая медиану обучающей выборки. |
| Backend store / artifact store | Хранилище параметров, метрик и состояния запусков MLflow / хранилище файлов, созданных этими запусками. Например, SQLite и каталог с моделями решают разные задачи. |
| Batch | Группа объектов, обрабатываемых вместе; отличается от числа одновременно отправленных запросов. |
| Calibration | Соответствие предсказанных вероятностей наблюдаемым частотам. |
| Candidate | Кандидат модели, ещё не обязательно разрешённый к выпуску. |
| Chart / release | Шаблоны ресурсов Kubernetes и значения Helm / конкретная установка chart с именем и историей ревизий. |
| ClearML Task / Agent | Запись отдельного запуска с кодом, параметрами и результатами / процесс, получающий подготовленные Task из очереди и исполняющий их. |
| Cardinality | Число различных комбинаций labels временных рядов. |
| Catchup / backfill | Создание прошлых scheduled runs / управляемая обработка исторических интервалов. |
| Concept drift | Изменение зависимости между признаками и target. |
| Data drift | Изменение распределения входных данных; само по себе не доказывает ухудшение качества. |
| Data leakage | Информация из оценки или будущего попала в обучение либо выбор модели. |
| Data interval | Интервал данных, за который выполняется запуск Airflow. Это предмет обработки, а не измеренная длительность исполнения DAG. |
| DAG | Ориентированный ациклический граф зависимых задач: например, проверить CSV → обучить модель → опубликовать прошедший проверку результат. Циклов между шагами нет. |
| Deployment / Pod / Service | Описание желаемых копий приложения / единица запуска контейнеров / стабильная точка доступа к выбранным Pod в Kubernetes. |
| Embedding | Векторное представление объекта в пространстве конкретной модели. |
| Feature | Входной признак; порядок и смысл признаков входят в serving-контракт. |
| Fit / predict | Подобрать параметры модели по обучающим данным / вычислить ответы готовой моделью для переданных признаков. |
| Flavor / signature | Способ упаковки и загрузки модели в MLflow, например sklearn или pyfunc / описание ожидаемых входов и выходов модели. Signature не проверяет качество её предсказаний. |
| Gate | Явная проверка, блокирующая публикацию результата при невыполненных условиях. |
| Idempotency | Повтор с теми же входами не создаёт повторного смыслового side effect. |
| Inference | Вычисление результата готовой моделью без её обучения. |
| KV cache | Сохранённые ключи и значения механизма внимания для уже обработанных токенов. Они ускоряют генерацию продолжения LLM, но расходуют память. |
| Lease / TTL | Запись Vault об аренде выданного динамического секрета с условиями истечения и отзыва / время до истечения. Срок действия есть и у токенов; возможность продления определяется типом доступа и политиками. |
| Lineage | Связь данных, кода, конфигурации, запуска, модели и выпуска. |
| Logical date | Логическая дата DAG run, не обязательно фактический момент запуска. |
| MAE / RMSE | Средняя абсолютная ошибка / корень средней квадратичной ошибки. |
| Model Registry | Каталог именованных моделей, версий и метаданных продвижения. |
| MLflow Experiment / run | Группа связанных запусков обучения / одна запись запуска с параметрами, метриками и ссылками на артефакты. |
| MRR / Recall@k | Среднее обратных рангов первого релевантного документа по запросам / доля релевантных документов, найденных среди первых k результатов. |
| ONNX / opset | Формат вычислительного графа / версия набора операторов. |
| p95 | Значение, ниже которого находятся примерно 95% наблюдений при заданном способе оценки. |
| Pipeline | Последовательность преобразований и модели в scikit-learn. Сохранённый Pipeline позволяет применять те же преобразования при предсказании, что и при обучении. |
| Prefill / decode | Обработка входного prompt / последовательная генерация следующих tokens. |
| Preprocessing | Преобразования данных перед моделью: заполнение пропусков, масштабирование или кодирование категорий. Их обучаемые параметры вычисляются только по обучающей выборке. |
| Qrels | Независимая разметка релевантности документов для запросов. |
| Readiness / liveness | Готовность принимать трафик / жизнеспособность процесса. |
| Release manifest | Связь версий данных, модели, image, chart и конфигурации конкретной поставки. |
| RRF | Сочетание ранжированных списков через reciprocal rank fusion. |
| Run / task instance | Конкретный запуск эксперимента / выполнение задачи графа. |
| Run key | Ключ логического результата, например сочетание хеша данных и настроек. Помогает отличить повтор попытки от работы над другим входом; сам по себе не обеспечивает идемпотентность. |
| Seed | Начальное состояние генератора случайности; не полная фиксация среды. |
| SDK | Библиотека для обращения к инструменту из программы. Например, ClearML SDK связывает Python-обучение с записью Task. |
| State | Сохранённая связь конфигурации Terraform с реальными ресурсами. |
| Target / label | Известный целевой результат, относительно которого обучают и оценивают модель. |
| Token | Элемент последовательности, полученный токенизатором из текста; может быть частью слова, знаком или целым словом. Число токенов отличается от числа слов. |
| Training-serving skew | Расхождение входов или преобразований между обучением и обслуживанием. |
| TTFT / TPOT | Время до первого полезного token / время на output token по явно заданному определению. |
| XCom | Механизм небольших межзадачных метаданных Airflow; не хранилище больших DataFrame. |
